# Добавление сайта через Android «Поделиться»

Задача пользователя: из браузера отправить ссылку приложению; разобрать ссылку, показать сформированное правило и добавить после подтверждения.

Изменения:
- AndroidManifest.xml: SEND text/plain, singleTask; VIEW для Telegram сохранён.
- MainActivity.kt: обработка EXTRA_TEXT при onCreate/onNewIntent, сохранение только нормализованного destination в Bundle, диалог подтверждения/отмены и ошибки, Telegram gate с сохранением предложения до входа, запись через существующий policy API и применение только после успешной проверки backend. Уже включённые родительские DOMAIN_SUFFIX/совпадающие правила не дублируются; отключённое редактируемое совпадение включается. Диалог предупреждает о сохранении существующего черновика. На ошибке можно повторить запрос. Новый share не очищается завершением старого запроса. Повторное применение неизменной политики не перезапускает туннель.
- SharedWebsite.kt: чистый JVM parser HTTP(S) в тексте, IDN, host/subdomains без расширения до registrable domain, IPv4/IPv6 host CIDR. Отбрасываются path/query/fragment/port; credentials, неоднозначный текст с разными host, неправильные адреса/порты и .ru/.su/.рф запрещены. Короткие ссылки не раскрываются по сети.
- SharedWebsiteParserTest.kt и дополнение docs/selective-vpn.md.

Проверки: сначала один тест поймал несовпадающий тип исключения для неверного IDN; исправлено на IllegalArgumentException. Повторная отдельная компиляция SharedWebsite.kt + SharedWebsiteParserTest.kt Kotlin compiler 2.2.10 из локального Gradle-кеша и запуск JUnitCore 4.13.2: OK (6 tests). Команда этой сессии: python3 /tmp/securevpn-run-share-tests.py (временный вспомогательный файл, не часть репозитория). Также XML manifest parsed, проверены SEND/text/plain, VIEW и singleTask; git diff --check прошёл.

Ограничения: полная Android-сборка/Compose не компилировались, sharesheet/onNewIntent/поворот экрана/Telegram возврат/серверное сохранение и VPN на телефоне не проверены. Предыдущие Gradle-проверки заблокированы отсутствием зависимостей/ошибками загрузки; не заявлять isolated parser tests как подтверждение Android UI. Следующий шаг — собрать APK при доступных зависимостях и пройти холодный/повторный share, отмену, гостевой вход, повторное правило и отказ backend на устройстве. Коммит и push не выполнялись.
