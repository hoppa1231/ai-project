# Добавление ned — требуется SSH-доступ

Поручение: добавить ssh ned с установленной Amnezia как дефолтную ноду приложения.

Перед работой прочитаны PROJECT_MEMORY.md, заметки fin-deployment и selective-vpn. Проверен dirty git status. Прямое SSH к ned: таймаут баннера (две попытки). С moscow порт2222 возвращает OpenSSH Ubuntu, порт22 отказ. ProxyJump moscow работает до аутентификации ned; настроенный пользователь max и назначенный ключ connect отклонены сервером (publickey,password). Приватные ключи не копировались; verbose подтвердил предложение именно назначенного ключа. Запрошены корректные пользователь/ключ, без отправки пароля или приватного ключа в чат.
