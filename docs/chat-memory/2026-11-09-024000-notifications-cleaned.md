# Очистка серверных уведомлений

По прямому поручению пользователя очищены уведомления на moscow в рабочей БД backend. До очистки:4 уведомления (все active),70 отметок прочтения. До удаления сохранён закрытый pg_dump только app_notifications/app_notification_reads в отдельном timestamp-каталоге /opt/securevpn-staging/notifications-clean-*. Содержимое сообщений/персональные данные не выводились.

В транзакции DELETE FROM app_notifications удалил4 записи; связанные отметки удалены ON DELETE CASCADE. Проверка в транзакции: обе таблицы пусты, COMMIT успешен. После очистки /health:status ok,db ok. Код и прочие данные не менялись. Локальный кеш уведомлений Android не проверялся.
