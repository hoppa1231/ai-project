# Android 1.3: задачи патча

Поручение пользователя от 2026-11-09. Координатор — основной агент; исполнители работают в общем checkout. Коммит и push не входят в поручение.

| Порядок | Исполнитель | Задача | Зависимость | Готовность |
|---|---|---|---|---|
| 1A | ui_patch | Системные панели, отсутствие вспышки при свайпе, ник Telegram с прокруткой, возврат из узлов, удаление «Общий ход», кнопка и диалог выбора приложений с иконками | Согласовать обязательные сервисы с 1C | Готово |
| 1B | vpn_tile | Плитка VPN в быстрых настройках, разрешение первого запуска, состояние и остановка | Hook MainActivity согласовать с 1A | Готово |
| 1C | routing_resources | Обязательные базовые сервисы в API/UI; проверенный GitHub источник заблокированных ресурсов, атрибуция и воспроизводимый импорт | Пользователь подтвердил обязательность базовых сервисов | Готово |
| 2 | координатор | Объединение, просмотр diff, Android/backend тесты, сборка и проверки на телефоне | 1A–1C | Готово |
| 3 | координатор | Backend rollout с сохранением действующих изменений; публикация APK через штатный механизм обновлений | 2 | Готово |
| 4 | координатор | Проверка публичных метаданных/подписи/APK и итоговая заметка с границами проверки | 3 | Готово |

Прямой маршрут по умолчанию и ограничения гостя Telegram-only сохраняются. Статические тесты не подтверждают работу VPN на устройстве.
