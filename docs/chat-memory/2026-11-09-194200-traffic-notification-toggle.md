# Переключатель карточки трафика в шторке

## Поручение
При выключении уведомлений в приложении отключать карточку с трафиком в шторке.

## Изменения
- `android-client/app/src/main/java/app/chspch/client/vpn/VpnNotificationSettings.kt`: сохранение show_traffic в отдельных SharedPreferences, default=true сохраняет прежний показ карточки после обновления.
- `MainActivity.kt`: переключатель читает/сохраняет настройку; разрешение POST_NOTIFICATIONS запрашивается только при включённой настройке. При запуске разрешение больше не принудительно включает выключенный переключатель.
- `Screens.kt`: подпись переключателя теперь описывает карточку трафика.
- `vpn/SingBoxVpnService.kt`: слушатель prefs немедленно перестраивает уведомление активной службы без перезапуска туннеля; снимается в onDestroy. При show_traffic=false создаётся обычное тихое foreground-уведомление на отдельном IMPORTANCE_LOW канале securevpn_status_quiet, без RemoteViews/счётчиков/прогресса/панели кнопок. При включении возвращается прежняя карточка. Системный обязательный foreground-статус сохранён: stopForeground для скрытия не вызывается. Трафик и состояние VPN продолжают учитываться.
