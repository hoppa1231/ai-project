# PNG-иконки и стеклянные лампы

Поручение: использовать форму трёх присланных PNG, убрать все видимые подписи в индикаторах, сделать объёмные лампы под стеклом, Google/ChatGPT и обновление10сек.

ConnectivityPanel.kt: вместо Canvas-эмблем Image с исходными alpha-масками и ColorFilter.tint. PNG в res/drawable-nodpi/ic_service_russian.png (орёл, третье вложение), ic_service_foreign.png (глобус, второе), ic_service_blocked.png (замок, первое). Побайтовое сравнение с вложениями true для всех3: формы/альфа не менялись. Все видимые Text в блоках удалены, сохранены contentDescription для доступности и ручное обновление нажатием.

GlassStatusLamp: металлический ободок/углубление, радиальное свечение активных цветов, стеклянный блик и отражение; нейтральный не светится. Без постоянной анимации.

Проверки: ya.ru, www.google.com/generate_204, chatgpt.com HEAD с timeout4s. Период10сек между началами циклов, без перекрытия запросов. repeatOnLifecycle RESUMED и удаление composable останавливают цикл при уходе со страницы/в фон. При403/429 нейтральный статус: сервер отвечает, но anti-bot/rate-limit не доказывает доступность сайта или сетевую блокировку; детали доступны через accessibility. Проверка идёт по фактическим правилам маршрутизации; набор серверных маршрутов в этом задании не изменялся.

assembleDebug SUCCESS20s, git diff --check passed. APK установлен adb -r -t с сохранением данных на подключённый телефон. Итоговый uiautomator: видимых названий/статусов0, российский и Google работают, ChatGPT HTTP403/нейтральный. Визуально просмотрен /tmp/vpn-lamps-final.png: исходные фигуры золотые, лампы со стеклом и ореолом, три блока в ряд без подписей. Первое получение UI сразу после старта вернуло null root, повторное прошло. Настройки экрана не менялись. Коммит/push не выполнялись.

Ограничения: ChatGPT HTTP403 не подтверждает доступ к чату; полный VPN-трафик в этом задании не тестировался. Период и lifecycle проверены по реализации, сетевой фон отдельно не профилировался.
