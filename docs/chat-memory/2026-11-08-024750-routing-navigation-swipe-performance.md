# Маршрутизация и перелистывание экранов

Поручение: кнопка маршрутизации не работает, перелистывание подтормаживает.

Причина по коду: MainActivity.kt блокировал переход гостю, меняя только telegramNotice в другой области экрана. Теперь кнопка всегда открывает RoutingScreen. Гость видит политику и явную кнопку входа; добавление/сохранение/переключение/удаление правил закрыты до Telegram-входа. Серверные ограничения сохранены. Screens.kt получает canEdit и onTelegramLogin.

Оптимизация: MainActivity.kt — направление/наличие свайпа через derivedStateOf; пиксельное смещение читается в graphicsLayer, а не при композиции дерева каждого кадра. Components.kt — фон PosterFrame строит девять групп зерна и точки в Path внутри drawWithCache, градиенты также кешируются; отдельный graphicsLayer для статичной текстуры. Вместо тысяч отдельных drawCircle каждый кадр используются кешированные пути. Дизайн и плотность текстуры сохранены.

Проверки и ограничения: окончательная assembleDebug после блокировки гостевых кнопок SUCCESS (13 секунд). git diff --check прошёл. ADB devices — пусто, поэтому реальное нажатие и время кадров на телефоне не измерены; оптимизация не является доказательством устранения всех лагов. VPN повторно не проверялся. Коммит/push не выполнялись.
