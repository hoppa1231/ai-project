# fra: проверка доступа перед добавлением

Задача: добавить SSH-хост fra как ноду VPN-сервиса. Прочитаны PROJECT_MEMORY.md и заметки о развёртывании ned; проверен git status, в checkout уже есть чужие изменения.

SSH fra работает с явным `-F /home/user/.ssh/config`: системный ssh config иначе отклоняется из-за прав /etc/ssh/ssh_config.d/20-systemd-ssh-proxy.conf. Удалённый пользователь max, Ubuntu 24.04.1, около 26 GiB свободно и 1.9 GiB RAM. Docker/podman/xray в PATH не найдены; TCP слушает только SSH 2222 и локальный DNS.

Блокер: `sudo -n true` отвечает `a password is required`. Административных изменений на fra, регистрации в backend и смены дефолтной ноды не было. Следующий шаг — получить административный доступ безопасным способом, затем установить отдельные компоненты, проверить реальный VPN-трафик и отзыв тестового клиента, зарегистрировать обычную fra без смены ned по умолчанию.
