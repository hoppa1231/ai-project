# Android UI: системные панели, маршруты, профиль и выбор приложений

Задача пользователя: исправить фон системных панелей, имя Telegram, вспышку при свайпе, возврат из узлов связи и оформление выбора приложений; убрать «Общий ход».

Изменения агента UI:
- `android-client/app/src/main/java/app/chspch/client/MainActivity.kt`: edge-to-edge с прозрачной status bar и фактическим фоном PosterFrame; navigation bar и нижняя подложка BurgundyDeep. Цвет иконок status bar зависит от темы. Удалён общий off-overlay: ранее он зависел от текущего экрана и менял яркость обоих слоёв при завершении свайпа. Добавлены возврат из Servers на Home и hook `VpnTileService.ACTION_CONNECT`, ожидающий завершения bootstrap и вызывающий существующий цикл разрешения/подключения только при Off.
- `Components.kt`: PosterFrame заполняет область status bar фоном экрана; карточка аккаунта показывает displayName (@username или fallback) с бесконечным basicMarquee при переполнении, колонка ограничена доступной шириной. Статические SettingsRow больше не показывают стрелку навигации.
- `Screens.kt`: нижняя кнопка «НАЗАД» в узлах; «Общий ход» удалён, действия назад/вход/сохранение сохранены отдельно. DEFAULT правила принудительно read-only даже для старого кеша. Добавление приложения стало настоящей контрастной кнопкой; диалог содержит поиск, иконки приложений, название/package и карточки с действием добавления. Собственный VPN пакет не предлагается.

Проверка: `git diff --check` прошёл. Gradle делегирован координатору, чтобы не запускать параллельные сборки. Runtime и визуальная проверка на телефоне на момент этой записи не выполнялись; изменение UI не доказывает работу VPN. Коммит/push не выполнялись. Следующий шаг: общая сборка координатора, визуальная проверка и публикация обновления.
