# Финальные уточнения сравнения скорости

Последующие прямые указания пользователя отменяют вариант без прибора: оставить один спидометр только для текущего замера, показывать только текущий и один предыдущий результат, убрать дату и время из обоих блоков.

Screens.kt: один SpeedReadout перед текущими метриками, предыдущий только SpeedMetrics, SpeedResultLabel без даты. SpeedTestHistory.kt: максимум два успешных результата. Время остаётся внутренним полем сохранённого результата, на экран не выводится.

На телефоне выполнен новый реальный замер; подтверждено, что предыдущий текущий результат перешёл в предыдущий блок, метрики совпали. Данные не подменялись. Сборки/14 JVM-тестов проходили, финальная сборка после удаления даты выполняется отдельно. Эти проверки не подтверждают работу VPN. Коммита/push нет.

Финальная сборка без даты прошла,14 JVM-тестов без ошибок; APK установлен. Следующее уточнение: единицы скорости сокращены до Мб/с (мегабиты, значения не пересчитываются).

Сборка с Мб/с: SUCCESS14s, тесты прошли, APK установлен. UI до последнего сокращения единиц проверен на телефоне: один спидометр, ровно текущий и предыдущий результат, даты отсутствуют.
