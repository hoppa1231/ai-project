# Иконка Windows-клиента

Задача: добавить иконку в Windows-версию приложения.

Использована существующая src/main/resources/images/icon.png, без нового дизайна. Создан desktop-client/packaging/windows-x64/chspch.ico:16/24/32/48/64/128/256px. build-launcher.py компилирует ICON resource в COFF через LLVM/MinGW windres в build staging и встраивает в Go EXE. Нужный compiler явно проверяется; README дополнен зависимостью. В main_windows.go ярлыки Desktop/Programs получают IconLocation Chspch.exe,0. build.gradle.kts использует тот же ICO для Windows nativeDistributions. Трей/окно уже имели исходный PNG.

Проверки: кросс-сборка Go launcher PASS; llvm-readobj подтверждает7 ICON и GROUP_ICON в PE. go test ./... для launcher PASS (GOCACHE=/tmp/chspch-icon-go-cache). Gradle --offline help PASS, конфигурация ICO валидна. Windows ZIP собран с локальным SHA-pinned JRE; CRC всех файлов, байтовое совпадение Chspch.exe/Install.exe с новым PE, наличие ICO и исходника IconLocation PASS. git diff --check PASS.
