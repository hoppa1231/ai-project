# Проверка Телеграма вместо Discord

Пользователь сообщил: Discord открывается, но индикатор не работает; попросил заменить проверку на Telegram.

ConnectivityPanel.kt: третья проверка https://telegram.org, accessibility-название Телеграм. Интервал10сек, HEAD, таймауты и обработка статусов сохранены. Домен уже включён в базовую Telegram-политику V13. Главная Telegram при выборе ответила HTTP200, robots.txt404, поэтому выбран корень. Discord robots.txt локально ответил200: причина прежнего отрицательного результата именно на телефоне не доказана. Проверка одного HTTP-адреса не равна работоспособности всего приложения.

assembleDebug/testDebugUnitTest SUCCESS11s; git diff --check прошёл. APK установлен с сохранением данных. После установки сервис VPN отсутствовал, UI показывал НА СВЯЗИ; Telegram сначала не отвечал. Переключением восстановлен SingBoxVpnService (isForeground=true); последующий UI dump подтвердил работает для ya.ru, Google и Telegram. Проверка Telegram относится к HTTPS-сайту, не сообщениям/звонкам. Исправление рассинхронизации UI после установки не входило в этот патч. Коммит/push не выполнялись.
