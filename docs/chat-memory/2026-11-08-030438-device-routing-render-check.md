Проверено uiautomator в окончательной сборке (/tmp/vpn-proof.xml), снимок /tmp/vpn-routing-proof.png. На главном экране ФИНЛЯНДИЯ · ТЕЛЕГРАМ.

Найдено на устройстве: кеширование тысячи овалов в Path всё ещё создаёт тяжёлые software path masks Skia. Components.kt: PosterFrame теперь создаёт растровую плитку 264x264 и повторяет ImageShader; градиенты/текстура в drawWithCache и отдельном graphicsLayer. Build assembleDebug SUCCESS, APK повторно установлен.
